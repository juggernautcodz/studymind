You are a senior full-stack engineer working inside a Replit workspace.

Your task is to build a production-ready MVP of a PAID student study web app that can realistically make money.

IMPORTANT GOAL
This app must be:
- Valuable enough that students will pay
- Structured so I can upsell a PRO subscription later
- Simple enough to ship quickly, but expandable

TECH STACK (REPLIT-FRIENDLY)
- Frontend: React + TypeScript + Vite (mobile-first, responsive)
- Backend: Node.js + TypeScript + Express
- Database: SQLite with Prisma ORM
- Auth: Email + password with JWT
- Payments: Stripe-ready (stubbed so the app runs without keys)
- File storage: Local filesystem (uploads/) with clean adapter for S3/GCS later
- AI features: Implement as provider interfaces with MOCK outputs so the app works end-to-end without external APIs

APP CONCEPT
A student study app where users:
1) Record lectures (audio) in the browser
2) Upload recordings → get AI-generated transcript
3) Convert transcript → clean, structured notes
4) Generate study materials automatically:
   - Flashcards
   - Quizzes (multiple choice MVP)
5) Organize everything visually using a MIND MAP (Mindly-style)
6) Upload photos of whiteboards/slides → OCR → attach to notes
7) Organize by:
   Semester → Course → Topic → Lecture

MONETIZATION (CRITICAL)
Design the app so it can generate revenue.

PLANS
- FREE:

- BASE (paid unlock / license):
  - More recordings (ex: 20 per month)
  - Notes + flashcards
- PRO (subscription):
  - High or unlimited recordings
  - Quizzes
  - Adaptive review
  - Exam mode
  - Export features (PDF later)

Implement:
- plan = 'FREE' | 'BASE' | 'PRO'
