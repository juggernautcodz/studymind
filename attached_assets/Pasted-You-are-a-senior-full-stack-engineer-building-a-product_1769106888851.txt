You are a senior full-stack engineer building a production-ready MVP in a Replit workspace.

GOAL
Build a PAID student study app (web-first, mobile-friendly) where students can:
1) Record lectures (audio) in the browser
2) Upload recording → get AI transcription
3) Convert transcript → structured notes
4) Generate study materials: flashcards + quizzes
5) Organize everything inside a Mind-Map UI (like Mindly)
6) Capture whiteboard/slides via image upload (camera-friendly) → OCR → attach to notes
7) Organize by Semester → Course → Topic → Lecture
8) Add auth + payment gating (Stripe-ready), with usage limits for AI minutes/storage (basic counters)

IMPORTANT CONSTRAINTS (Replit)
- Build as a monorepo:
  - Frontend: React + TypeScript + Vite
  - Backend: Node.js + TypeScript + Express
  - DB: SQLite using Prisma (easy on Replit) OR Postgres if available (choose SQLite for MVP)
  - File storage: local filesystem (uploads/) for MVP with a clean adapter for S3/GCS later
- AI services: implement as “providers” with stubs:
  - TranscriptionProvider
  - NotesProvider
  - FlashcardsProvider
  - QuizProvider
  - OcrProvider
